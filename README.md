# Gorod Splash Animations

Motion-design source and browser previews for the Gorod product splash/loading experience.

## Repository contents

- Adobe After Effects source (`.aep`).
- Bodymovin/Lottie-style JSON animation exports.
- HTML preview files for multiple splash variants.
- Alternative animation data sets in `splash 2/` and `2/`.

## Preview locally

```bash
python -m http.server 8000
```

Open `demo.html` or one of the nested `demo.html` files in a browser.

## Tech stack

- Adobe After Effects
- JSON vector-animation exports
- Static HTML preview player

## Status

Archived motion-design deliverable preserved as portfolio and implementation reference.
