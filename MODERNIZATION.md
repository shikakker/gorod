# gorod — Preservation & Portfolio Roadmap

This repository contains a large HTML demo, substantial JSON data and original motion source (`.aep`) assets.

## 10 tasks

1. Document the project's date, purpose, role and original product context.
2. Preserve the current demo as an immutable historical snapshot before any cleanup.
3. Inspect `data.json` and explain what information model powers the demo.
4. Separate embedded demo code/assets into understandable source sections where feasible.
5. Optimize portfolio delivery without altering the historical design artifact.
6. Export lightweight previews of the After Effects splash work while retaining source provenance.
7. Add screenshots/GIF/video references showing key interactions and motion.
8. Audit third-party libraries/assets and attribution/licensing before public promotion.
9. Explain which parts were design, motion, frontend implementation or data work—without inflating scope.
10. Position the project as historical evidence of interactive/product design depth rather than forcing it into a modern SaaS framing.

## Portfolio value

High historical value: the combination of interactive demo, data and motion source can substantiate long-term hands-on digital product work.
